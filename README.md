## Featured Projects

### [Semesta](https://app.cognitivemaxxing.com) — flagship
A full-stack study OS I designed, built, and deployed solo, turning progressive-overload training principles into a study system.

- Research-based **Cognitive Load Engine** (power-law duration scaling, mastery discounting, fatigue modeling)
- **FastAPI + PostgreSQL + SQLAlchemy** backend, Alembic migrations, 300+ test pytest suite
- **React** frontend, **Google OAuth** + JWT auth, **Claude API** for in-app AI features
- Deployed on **AWS** (EC2, RDS, S3, CloudFront, SES) behind Nginx, with GitHub Actions CI/CD

**Stack:** FastAPI · PostgreSQL · SQLAlchemy · React · AWS · Docker · Claude API
**Live:** [app.cognitivemaxxing.com](https://app.cognitivemaxxing.com)

### [AI Engineering Lab](https://github.com/tyudope/ai-engineering-lab)
A workspace for building AI-powered backend services, focused on structured output, prompt design, and reliable LLM integration.

| Project | Description | Key Concepts |
|---------|-------------|--------------|
| **DreamSense** | AI dream reflection with structured, safe output | Output contracts, safety guardrails, schema-first design |
| **AI DJ** | Generates DJ-ready playlists from a theme & emotional flow | Strict schema validation, structured generation |
| **Uber Meal Recommender** | Context-aware meal recs from order history | Prompt enrichment with DB context, SQLite |
| **Study with AI** | AI study-plan analyzer | SQLAlchemy ORM, LLM wrapper pattern, dependency injection |

**Stack:** FastAPI · Pydantic v2 · OpenAI API · SQLAlchemy · Python

### [THRESHOLD](https://github.com/tyudope/THRESHOLD)
A Papers-Please-inspired game in pure Python, built as a showcase of clean software engineering.

- Clean OOP with **composition over inheritance**, functional core / imperative shell
- Sealed custom exception hierarchy, terminal + tkinter GUI sharing one domain layer
- Follows solid SDLC and software-engineering principles throughout

**Stack:** Pure Python (standard library only)

### [Perfume Recommender](https://perfume-recommender-vj81.onrender.com)
A perfume recommendation system, ML scoring (cosine similarity, weighted ranking) plus GPT-4o-mini reasoning for personalized picks.

- Hybrid weighted ranking (content similarity, longevity, community ratings)
- **OpenAI GPT-4o-mini** for human-like explanations, rate-limiting via SlowAPI
- Containerized with **Docker**, deployed on **Render**

**Stack:** FastAPI · Python · pandas · scikit-learn · OpenAI API · Docker
